## 🛠️ Stack & Arquitetura Atual
- **Framework:** Next.js 16.4.3 (App Router) + React 19 + Turbopack
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 + Framer Motion + Lucide React
- **IA / Tutor:** Google Gemini (`@google/genai`)
- **Gamificação & UI:** Canvas Confetti, componentes interativos de terminal e sandbox de vulnerabilidades web.
